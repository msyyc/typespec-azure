:::caution
The Relationship base type is **experimental**. Applying it in a provider namespace emits the
`basetypes-experimental` warning, which you must explicitly suppress while the feature is
experimental.
:::

A Relationship represents a directed association from a source resource or scope to a target
entity. Use the models in `Azure.ResourceManager.BaseTypes.Relationships`:

```typespec
using Azure.ResourceManager;
using Azure.ResourceManager.BaseTypes.Relationships;
```

## Define relationship properties

Derive the property bag from `RelationshipProperties`. It supplies `baseTypes`, `sourceId`,
`sourceTenant`, `targetId`, `targetTenant`, and `provisioningState`; `provisioningState` is optional
and read-only. You can provide a custom provisioning-state union and add provider-specific metadata:

```typespec
@Azure.Core.lroStatus
union DependencyProvisioningState {
  ResourceProvisioningState,
  Accepted: "Accepted",
  Provisioning: "Provisioning",
  Deleting: "Deleting",
  string,
}

model DependencyProperties
  is RelationshipProperties<ProvisioningState = DependencyProvisioningState> {
  description?: string;
}
```

## Define the relationship resource

`Relationship<Properties>` creates an extension resource and automatically applies
`@azureBaseType` with the current Relationship contract. Add the standard resource-name spread and
suppress the experimental warning:

```typespec
#suppress "@azure-tools/typespec-azure-resource-manager/basetypes-experimental" "Experimental BaseTypes"
model Dependency is Relationship<DependencyProperties> {
  ...ResourceNameParameter<
    Resource = Dependency,
    KeyName = "relationshipName",
    SegmentName = "dependencies",
    NamePattern = "^[a-zA-Z0-9_.-]{1,64}$"
  >;
}
```

## Define extension-resource operations

Relationship resources can target any ARM scope. Define a reusable interface with the operation
templates in `Azure.ResourceManager.Extension`, then instantiate it with the supported scope:

```typespec
interface DependencyOps<Scope extends Azure.ResourceManager.Foundations.SimpleResource> {
  get is Extension.Read<Scope, Dependency>;
  create is Extension.CreateOrReplaceAsync<Scope, Dependency>;
  update is Extension.CustomPatchAsync<
    Scope,
    Dependency,
    Azure.ResourceManager.Foundations.ResourceUpdateModel<Dependency, DependencyProperties>
  >;
  delete is Extension.DeleteWithoutOkAsync<Scope, Dependency>;
  list is Extension.ListByTarget<Scope, Dependency>;
}

@armResourceOperations
interface Dependencies extends DependencyOps<Extension.ScopeParameter> {}
```

The
[`use-relationship-required-properties`](/docs/libraries/azure-resource-manager/rules/use-relationship-required-properties)
rule verifies that a resource declaring Relationship base-type conformance is an extension resource
with the required schema.
